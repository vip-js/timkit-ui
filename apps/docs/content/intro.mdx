# What is Timkit UI?

Timkit UI is a collection of modern UI components and website templates, built on top of <br/>React/Nextjs with Tailwind CSS, <br/>
the components are beautiful designed, expertly crafted, allow you to build beautiful websites.

## Why Timkit UI?

First, Timkit UI is fully free, and open source, you don't need to pay anything to use it, <br/>
and we are working on it full-time, so we'll keep improving, and adding more UIs, <br/>
the second thing if you’re working on a large project that requires <br/> a high level of UI customization or you find yourself <br/>repeating the same UI patterns across projects, consider creating an internal UI library, <br/>
and in this case Timkit UI is a great choice. You should definitely use it.

| Dependency       | Version   | Notes                                                                  |
| :--------------- | :-------- | :--------------------------------------------------------------------- |
| **React**        | `^19.0.0` | Required for server components & actions support found in some blocks. |

| **Node.js**      | `>=18`    | Required for CLI and build tools.                                      |

## Consumption Mode

You can use Timkit UI in two ways, depending on your needs:

### 1. Source Code (CLI / Registry) - **Recommended**

Use the CLI to copy component source code directly into your project.

- **Control**: You own the code. Modify styles and logic freely.
- **Performance**: Zero dead code. Only what you use is included.
- **Command**: `npx @timui/cli add button`

### 2. NPM Package (`@timui/react`) - **Alternative**

Install as a standard library dependency.

- **Convenience**: Easy to upgrade via `npm update`.
- **Standardization**: Good for teams wanting a locked version across projects.
- **Command**: `npm install @timui/react`
